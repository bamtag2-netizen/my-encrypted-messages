# رسائلي المشفرة

برنامج ويب بسيط يحوّل النص العربي إلى لغات رمزية مبتكرة، ويعيد الرموز إلى العربية.

## المزايا
- ترجمة في الاتجاهين: عربي ← رموز، ورموز ← عربي.
- أربع لغات جاهزة: الأشكال الهندسية، الرونية، نقاط وشرطات، حساب الجُمَّل.
- إضافة لغات جديدة من داخل البرنامج، مع توليد رموز عشوائية.
- **المفتاح السري:** كلمة سر تعيد ترتيب الرموز على الحروف، فلا يقرأ الرسالة إلا من يعرفها.
- **التشفير المتغير:** يتغير شكل الحرف حسب موقعه في الرسالة، فيصعب كسره بتحليل تكرار الحروف.
- **بصمة المفتاح:** أربعة رموز تتأكد بها أنت وصديقك أنكما كتبتما نفس كلمة السر، دون كشفها.
- لوحة رموز للكتابة عند فك التشفير.
- تصدير اللغة واستيرادها بصيغة JSON لمشاركتها مع الآخرين.
- يعمل بالوضع الفاتح والداكن، وعلى الجوال.

## الملفات
| الملف | المحتوى |
|---|---|
| `index.html` | هيكل الصفحة |
| `style.css` | التنسيق |
| `app.js` | منطق التشفير وفك التشفير وقاعدة اللغات |

## التشغيل
افتح `index.html` في أي متصفح. لا يحتاج البرنامج إلى خادم أو تثبيت.

## النشر على GitHub Pages
1. ارفع الملفات إلى مستودع جديد.
2. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة يصبح البرنامج متاحاً على `https://اسم-المستخدم.github.io/اسم-المستودع/`.

## إضافة لغة جاهزة داخل الكود
في `app.js` أضف عنصراً إلى المصفوفة `BUILTIN`:

```js
{id:'mylang', name:'لغتي', dir:'rtl', sep:'', wordSep:' ', builtin:true,
 desc:'وصف قصير.',
 map:zip(LETTERS, Array.from('...31 رمزاً بترتيب الحروف...'))}
```

ترتيب الحروف: `ا ب ت ث ج ح خ د ذ ر ز س ش ص ض ط ظ ع غ ف ق ك ل م ن ه و ي ء ة ى`

- `sep`: الفاصل بين الحروف (فارغ إذا كان كل رمز حرفاً واحداً).
- `wordSep`: الفاصل بين الكلمات.
- `dir`: اتجاه عرض الرموز (`rtl` أو `ltr`).

## كيف يعمل المفتاح السري
- تتحول كلمة السر إلى رقم ثابت (بذرة)، ومنه يُعاد ترتيب رموز اللغة المختارة على الحروف. نفس كلمة السر تعطي دائماً نفس الترتيب.
- في التشفير المتغير تُضاف لكل حرف إزاحة مختلفة مأخوذة من كلمة السر حسب موقعه، فتظهر «ا» مثلاً بأشكال مختلفة في الرسالة الواحدة.
- كلمة السر لا تُحفظ في البرنامج ولا تُرسل مع الرسالة.
- الحماية هنا مناسبة للخصوصية أمام الآخرين، وليست بديلاً عن برامج التشفير الاحترافية.

## ملاحظة
اللغات التي يضيفها المستخدم تُحفظ في متصفحه فقط (localStorage). لمشاركة لغة، استخدم قسم «تصدير واستيراد».
